# Challenge5-Christian-Toliver
1. The sunset scene was the easiest to create because I only had to adjust the light color, direction, and ambient light.

2. The moonlight scene looked the most realistic because the darker lighting and blue color made it look like nighttime.

3. Ambient light changed how bright or dark the whole scene appeared. Lower ambient values made the scene feel darker and more dramatic.

4. Light direction affected which sides of the objects were bright and which sides were dark.

5. The orange-red campfire lighting produced the strongest visual effect because it made the scene look very different from the normal lighting.

6. Game developers spend a lot of time adjusting lighting because lighting affects visibility, mood, realism, and how the player experiences the scene.

7. For a horror game, I would use very low ambient lighting with dim blue or red lighting because darker scenes can make the environment feel more tense and unsettling.
